## 📝 Featured Production Projects

### 🪙 **SpendGrid – Decoupled Full-Stack Expense Ecosystem**
* **Overview:** A high-performance financial tracking ecosystem built on a compiled, modular backend architecture to support intense cross-origin data mutations.
* **Key Architecture:** Built a domain-driven Go REST API with custom 16KB header buffers, integrated serverless GORM connection pooling with Neon PostgreSQL, and implemented strict secure cross-site session handshakes via `SameSite=None` and `HTTPOnly` JWT tokens.
* **Tech Stack:** `Go (Golang)`, `Fiber v2`, `GORM`, `Neon PostgreSQL`, `Next.js (App Router)`, `Axios`
* 🔗 **Backend API:** [spendgrid-2.onrender.com](https://spendgrid-2.onrender.com) | **Frontend:** [spend-grid-lovat.vercel.app](https://spend-grid-lovat.vercel.app)
